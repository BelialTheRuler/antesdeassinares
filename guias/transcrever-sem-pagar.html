Transcrição é das poucas categorias onde o open source ganha de forma limpa. Os modelos são bons, correm em máquina normal, e o áudio nunca sai do teu computador — o que interessa se estás a transcrever uma entrevista ou uma reunião de clientes.

Veredicto

Para a maioria das pessoas: Whisper large-v3 e não se fala mais nisso. É o que dá menos problemas em português e corre em hardware modesto.

Se transcreves por profissão e o volume é grande, vale a pena o trabalho de montar o Parakeet.

Qual para quê

  • Whisper large-v3 — o polivalente. Se só queres uma escolha e não queres pensar mais, é esta. Lida bem com português.
  • NVIDIA Parakeet TDT — o mais rápido para volume. Se tens horas de áudio para processar de uma vez, é aqui que ganhas tempo.
  • NVIDIA Canary-Qwen 2.5B — o mais preciso em inglês. Para português não é a escolha óbvia.
  • Moonshine — feito para correr no dispositivo, onde não há nuvem nenhuma. Telemóvel, Raspberry Pi, offline.

Porque é que isto importa mais do que parece

Os serviços comerciais de transcrição cobram por minuto e recebem o teu áudio. Para uma entrevista pública é indiferente. Para uma reunião com um cliente, uma consulta ou uma gravação com dados pessoais, é uma decisão de privacidade — e o RGPD não gosta de ambiguidade nesse ponto.

Correr o modelo localmente resolve as duas coisas ao mesmo tempo: custo e privacidade.
